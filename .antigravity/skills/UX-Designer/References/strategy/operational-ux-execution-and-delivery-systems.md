# UX Prioritization & Severity Governance Systems

## Workflow Severity & Delivery Prioritization Evaluation

UX delivery prioritization should evaluate:
- workflow criticality
- trust impact
- operational frequency
- implementation leverage
- delivery risk
- behavioral disruption cost

### Operational Priority Weighting

Prioritize:
- high-frequency workflow friction
- trust-sensitive failures
- workflow blockers
- operational instability

before:
- aesthetic refinement
- decorative optimization
- non-critical motion polish

## UX Severity Classification Matrix

| Severity Level | Operational Impact | Delivery Action |
|---|---|---|
| P1 — Critical | Workflow blockage, trust destruction, catastrophic instability | Block release until resolved |
| P2 — High | Core workflow degradation, repetitive operational friction | Resolve during active delivery phase |
| P3 — Medium | Recoverable instability, localized inconsistency | Backlog for stabilization cycle |
| P4 — Low | Non-critical refinement, cosmetic optimization | Defer until structural stability |

## Implementation Leverage Optimization

Delivery prioritization should favor:
- low-effort improvements
- high-frequency impact
- operational throughput gains
- cross-workflow operational impact

### Example

Prefer:
- correct mobile keyboard invocation

over:
- expensive non-critical interaction enhancements

when workflow impact is significantly higher.

# Operational Delivery Trigger Systems

## Delivery Trigger → Operational Response Mapping

| Delivery Trigger | Operational Response |
|---|---|
| Engineering declares implementation complexity too high | Extract core workflow objective and design low-cost fallback systems |
| Redesigned workflow causes workflow completion decline | Deploy telemetry, replay analysis, and friction isolation before iteration |
| Primary workflow relocation occurs | Introduce migration guidance, redirects, onboarding cues, and temporary fallback pathways |
| Design-system inconsistency spreads across teams | Enforce centralized governance and cross-team UX audits |
