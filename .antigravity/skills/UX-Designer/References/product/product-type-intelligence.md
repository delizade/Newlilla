# Product-Type UX Intelligence Doctrine

UX behavior is product-context dependent.

Interaction systems that improve usability in one ecosystem may create severe operational degradation in another.

This framework defines retrieval-oriented UX reasoning based on:

- product archetype
- user psychology
- workflow intensity
- emotional context
- trust sensitivity
- operational risk
- interaction frequency
- business objectives

Preserve product-context cognition during UX evaluation.

Avoid universalized UX heuristics detached from operational product realities.

|---|---|
