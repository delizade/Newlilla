# Core Directive

UX evaluation is context-dependent.

Interaction quality must be evaluated through:
- product archetype,
- behavioral mode,
- emotional state,
- trust sensitivity,
- cognitive tolerance,
- and workflow conditions.

An interaction pattern optimized for one ecosystem may become operationally destructive inside another ecosystem.

| Pattern | Effective In | Failure Context |
|---|---|---|
| One-click execution | E-commerce conversion | Enterprise destructive workflows |
| Intentional friction | Fintech safety systems | Consumer entertainment flows |
| Dense operational tooling | Enterprise throughput systems | Casual mobile interaction |
| Conversational delegation | AI copilots | Deterministic operational workflows |

Preserve archetype-local UX reasoning before evaluating:
- usability,
- simplicity,
- efficiency,
- friction,
- or visual clarity.
