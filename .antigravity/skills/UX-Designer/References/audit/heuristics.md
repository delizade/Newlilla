# Core Interaction Stability Heuristics

## Progressive Disclosure Systems for Cognitive Load Deferral

### Principle

Cognitive load should distribute progressively across interaction flow rather than surfacing simultaneously.

### Healthy State

- Advanced controls appear only after intent escalation
- Secondary complexity remains contextually gated
- Core workflows preserve low-initial cognitive overhead

### Failure Patterns

- Wall-of-configuration interfaces
- Premature complexity exposure
- Simultaneous capability surfacing
- Dense first-contact workflows

### Operational Ontology

`[Cognitive Overload: Premature Complexity Surfacing]`

---

## Recognition-Oriented State Persistence Systems

### Principle

Human working memory is volatile and unreliable under workflow interruption.

### Healthy State

Critical operational context remains persistently visible:

- filters
- variables
- selections
- workflow state
- temporary memory dependencies

### Failure Patterns

- Cross-screen memorization dependency
- Hidden workflow variables
- Lost filter visibility
- State reconstruction requirements

### Operational Ontology

`[Friction: Forced Recall / State Amnesia]`

---

## Momentum Preservation & Workflow Continuity Systems

### Principle

Interaction momentum should remain uninterrupted during primary-task execution.

### Healthy State

- Keyboard-first operability
- Inline workflow continuation
- Auto-focused interaction surfaces
- Context-preserving expansion systems

### Failure Patterns

- Modal hijacking
- Forced page transitions
- Context-switch interruption
- Workflow reset behavior

### Operational Ontology

`[Workflow Interruption: Context Switch Penalty]`
