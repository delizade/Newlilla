# Attention Systems & Saliency Architecture

Visual attention is:
- finite
- competitive
- zero-sum

Interfaces compete for:
- gaze priority
- cognitive bandwidth
- perceptual saliency
- subconscious processing dominance

## Preattentive Saliency Systems for Primary Action Recognition

The brain processes:
- size
- contrast
- color
- motion

within approximately 200ms before conscious reading begins.

Primary actions should remain:
- instantly perceptible
- visually dominant
- cognitively unambiguous
- hierarchy-stable

If users must consciously search for the primary action:

`[Attention Failure: Primary Action Discovery Friction]`

### Healthy Saliency Architecture

- One dominant interaction priority
- One visually dominant focal region
- Stable hierarchy contrast
- Controlled accent-color concentration

### Failure Patterns

- Multiple high-contrast CTAs
- Competing visual anchors
- Excessive accent-color saturation
- Parallel hierarchy systems
- Unstable visual weighting

`[Attention Fragmentation: Competing Focal Points]`  
`[Saliency Failure: Hierarchy Ambiguity]`
